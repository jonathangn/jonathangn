# Hi, I'm Jonathan 👋

**Software Engineer · Full-stack, Front-end & Mobile · AI agents & LLM integrations**

I've spent 5+ years building software for clients, and the last 3+ shipping FinTech products in production for banks in Ecuador, Colombia and Peru (Banco Bolivariano, Mibanco, Fondo Nacional del Ahorro). I work end to end: Angular, React/Next.js and Ionic/Capacitor on the front end, Node.js/Express API gateways and Java/Spring Boot on the back end, and third-party integrations in the field with client QA teams.

### What I've built

- 🏦 **Banking-agent network for Banco Bolivariano (Punto BB):** lead front-end engineer of the agent app (Ionic/Capacitor), the web portal (Angular) and API gateway features (Node.js). Integrated Facephi biometric onboarding, payments for 6 bill collectors and OTP device binding.
- 🎨 **Nebula UI:** designed and built a 40-component Angular 21 design system as its sole developer, with Storybook, Vitest, design tokens, dark mode, accessibility and i18n. It's used by an ERP and a document-management product.
- 🤖 **AI agents:** I run a self-hosted AI agent with LanceDB vector memory, local Ollama embeddings and Node-RED tools that call LLMs, and I built an MCP-based verifiable-credentials agent prototype. I work daily with coding agents (Claude Code, Cursor, Codex) using Spec-Driven Development and human review.
- 🧩 **fin-elements** *(in progress)*: an open-source Lit 3 Web Components library for banking UIs on Open Cells.
